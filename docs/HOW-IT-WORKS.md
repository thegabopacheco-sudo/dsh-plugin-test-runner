# How dsh-plugin-test-runner works

Ejecuta y resume tests de un proyecto local para DeepSeek Harness: detecta scripts (npm/pnpm/yarn/pytest), corre con timeout y reporta pass/fail con salida real.

## Architecture

```
DSH ──MCP stdio──► server.mjs (single-file bundle)
                    └─ local plugin logic
```

## Safety

- Read by default; actions require `confirm:true`.
- `read-only` mode via environment variable.
- Allowlists where applicable.
- Audit at `<DSH_HOME>\cache\test-runner\audit.jsonl`.
- Action rate limit.

## Validation

End-to-end tests with the official MCP client (`@modelcontextprotocol/client@2.2.0`)
and the packaged artifact (`npm pack` → `postinstall` → deployed server).
